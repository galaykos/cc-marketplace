# Codex dispatch settings

Role labels describe expertise; they do not establish a cross-vendor model ranking. Resolve role instructions from this package's references/agents directory and available skills. Use the actual subagent tool schema when available and permitted. Inherit the configured session model and effort unless the user explicitly selected another supported setting. An unavailable requested model is a limitation to report, not a reason to substitute a guessed tier.

The native ultra skill adds bounded review and recorded decisions. Legacy auto/opus/fable/haiku/sonnet pins and Workflow agent() effort fields are not executable Codex settings. If independent delegation is unavailable, perform the rubric inline and label the result a single-model review. Do not claim an automatic escalation or corroborated panel.
