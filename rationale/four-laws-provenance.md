# Provenance of the four laws

Moved here from CLAUDE.md on 2026-08-11 — repo history, not an actionable rule;
CLAUDE.md keeps the one-clause glosses and the pointer to the canonical home
(the `claude-authoring` plugin's `authoring-skills` skill, "The four laws",
derivation in its `references/doctrine.md`).

Proportionality, honest limitation, the theater test, admission: each was
independently re-derived across this marketplace under a different subject
heading, by authors who did not know the others had written it. A principle
with no home gets rewritten every time it is needed. The evidence — which
sites, how many, in which vocabularies — lives with the doctrine
(`references/doctrine.md`), not with this note.

Related history, from the doc-location rule in CLAUDE.md: until `rationale/`
existed, the "no design/docs dirs inside plugins" rule named no reachable
destination for documents that genuinely had to be tracked — `taskmaster-docs/`
and `docs/` are gitignored, so "move it there" was deletion, not preservation.
`rationale/` was created to be that destination; this file is an instance of
the rule it documents.
