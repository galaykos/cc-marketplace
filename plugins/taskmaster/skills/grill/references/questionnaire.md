# Questionnaire — for a row only a named third party can answer

grill writes one when a ledger row is "not mine to answer" and a named person holds it.
The row turns ASSUMED with a named default whose Source is this file; when the answers
return, grill's update path amends that row and the spec in place. Standing: **recorded** — no script reads
the file or checks its shape.

Ask the user two things: the recipient, and what the answers must settle. Never
interview them about the subject — they do not hold it, which is why the file exists.

Write `taskmaster-docs/questionnaires/YYYY-MM-DD-<slug>-<recipient>.md`, one recipient
per file (`<recipient>` a kebab of the role or name), in this order:

1. **Purpose** — one line: why the file exists and the decision at stake.
2. **Context** — one paragraph for a reader who never saw this session: the task, what
   is settled, what is open. No ledger, no path they cannot open.
3. **How to answer** — the deadline, and that "I don't know" is an answer.
4. **Questions** — most important first, each followed by an empty answer stub (`> `);
   one topic each, as grill's own question rules say.
5. **Catch-all** — one open question last, for whatever the list above missed.
