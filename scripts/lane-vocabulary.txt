# lane vocabulary — every `owns` noun any plugins/*/lane.tsv may use.
#
# WHY THIS FILE EXISTS. pc_lanes_territory compares `owns` as a STRING, so two
# artifacts doing one job pass the gate by picking different nouns — and every
# plugin here had done exactly that. The clearest case: twelve review-phase
# agents, each with a unique noun (stack-agnostic-diff-review,
# markup-and-style-review, component-logic-review, typecheck-and-lint-run, ...),
# all green, all contending for one `.tsx` diff. The gate could not see it, and
# its own header names that as the defect it was built for.
#
# WHAT THIS CHANGES. It does not merge anyone's territory — it makes INVENTING a
# noun a deliberate, reviewed act instead of the invisible default. Adding a
# thirteenth reviewer now means opening this file and typing the new noun
# directly beneath the twelve that already exist. That is a social catch, not a
# mechanical one, and saying so is the point: nothing here proves two nouns mean
# different things.
#
# Grouped by phase so near-neighbours sit together. Alphabetical within a phase.
# Standing: gate — validate.sh fails on an `owns` value absent from this file.
